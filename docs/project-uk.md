# PIXEL//BRIEF — вебзастосунок для стислого викладу документів

PIXEL//BRIEF — університетський проєкт, що демонструє інтеграцію великої мовної моделі у повноцінний вебзастосунок. Його мета — перетворювати довгі тексти та документи на зрозумілі стислі виклади зі збереженням основних ідей, фактів і мови оригіналу.

Користувач може вставити текст або завантажити файл TXT, MD, PDF чи DOCX, обрати короткий виклад на 1–2 речення або стандартний на 3–4 речення, отримати результат і скопіювати його. Адаптивний інтерфейс виконано в ретро-піксельному стилі з темним тлом, світло-зеленими акцентами та оригінальною ілюстрацією цифрової планети. Передбачено стани очікування, обробки, успішного завершення й помилки, а також керування з клавіатури.

Фронтенд реалізовано за допомогою HTML5, CSS3 та JavaScript без фреймворків. Сервер написано на Python із використанням FastAPI. Для отримання тексту з PDF застосовується pypdf, а з DOCX — python-docx. Сервер і клієнтська частина працюють в одному застосунку.

Генерація викладу виконується через Groq Chat Completions API та офіційний Python SDK. Типова модель — openai/gpt-oss-20b; її можна змінити через змінну середовища. Кожне коректне звернення на узагальнення виконує рівно один запит до мовної моделі. Автоматичні повтори SDK вимкнено. Поділ документа на частини з окремими AI-запитами, додаткове редагування результату моделлю та агентні конвеєри не використовуються.

Системний промпт вимагає повертати лише виклад без вступних фраз, не вигадувати факти, не додавати відомостей поза джерелом і сприймати вміст документа як дані, а не інструкції. Мовна модель може помилятися, тому важливі факти потрібно звіряти з оригіналом.

API-ключ налаштовується через GROQ_API_KEY або вводиться користувачем у захищене поле для поточного запиту. Ключ не зберігається у localStorage, а браузер звертається до Groq лише через сервер. Реалізовано перевірку розміру файлів і довжини тексту, обробку порожніх, пошкоджених і зашифрованих документів, PDF без текстового шару, помилок авторизації, обмеження частоти запитів та тайм-аутів. OCR у цій версії не підтримується.

Проєкт містить автоматизовані тести з імітацією відповідей API, документацію для локального запуску та Docker-конфігурацію для розгортання на Hugging Face Spaces через порт 7860.
